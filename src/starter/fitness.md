# Fitness

A one-page web app. Today’s session. Three moves.

# Visual rules
Colour: ink #141414 · paper #F7F4EE · accent #E23D28 · mute #6E6A64
Type: Syne for the session name. Outfit for the moves. Never Inter.
Space: 8px grid. Gutter 32px. List gap 16px. Gaps not sibling margins.
Radius: 12px on the start button. 0 on the list.
Icons: one set, line, 24px. No fire, no medals, no emoji.
Voice: instructional. “Do five.” Not “crush your goals.”
Never: rings, streak flames, before-after photos, fake heart-rate, gradient text.

# Product
Title: today’s session. Three rows: move, reps. One filled button: Start.
Done = I can start the session from the preview.
